# Pawan Rathod — Portfolio

A modern, responsive developer portfolio built with vanilla HTML, CSS, and JavaScript. Deployed on GitHub Pages.

🔗 **Live Site**: [pawanrathod45.github.io/portfolio](https://pawanrathod45.github.io/portfolio)

---

## Features

- **Live Coding Canvas Animation** — Hero section features a real-time animated code stream using HTML5 Canvas and `requestAnimationFrame` (60fps)
- **Dark Charcoal Theme** — `#0d1117` background with `#58a6ff` blue accents
- **Responsive Design** — Fully mobile-friendly layout
- **Smooth Animations** — Scroll-triggered fade-ins, hover effects, and transitions
- **EmailJS Contact Form** — Functional contact form with no backend required
- **Tech Stack Cards** — Fan-stacked skill cards with real devicon logos
- **Achievements Carousel** — Auto-scrolling carousel with manual navigation
